이런 상황에서 필요합니다

PDF 자료에서 특정 페이지의 그림이나 표만 따로 캡처해서 써야 할 때, PDF 뷰어가 없는 곳에 미리보기 이미지로 공유해야 할 때, 또는 PDF 자체 용량을 줄이거나 여러 PDF를 재합치기 위해 먼저 이미지로 뽑아둬야 할 때처럼, PDF 페이지를 이미지 파일로 바꿔야 하는 상황이 있습니다. 이 페이지에서는 image-toolbox의 PDF→이미지 기능으로 이를 처리하는 방법을 설명합니다.

사용 방법

1. PDF 파일 선택. 변환하고 싶은 PDF를 선택하거나 업로드 영역에 끌어다 놓습니다. 최대 20MB, 최대 300페이지까지 지원합니다.

2. 변환 진행 확인. 브라우저 안에서 각 페이지가 PNG 이미지로 변환됩니다. 페이지 수가 많을수록 처리 시간이 더 걸립니다.

3. 페이지별로 다운로드. 변환이 끝나면 페이지마다 "페이지 N 다운로드" 링크가 생깁니다. 필요한 페이지를 하나씩 눌러 저장하면 됩니다.

알아두면 좋은 점

이 기능은 페이지별로 개별 다운로드 링크만 만들어줄 뿐, 여러 페이지를 압축파일 하나로 묶어 한 번에 내려받는 기능은 없습니다. 페이지 수가 많은 PDF라면 다운로드에 시간이 조금 걸릴 수 있습니다. 또한 변환된 PNG는 순수 이미지라서, 원본 PDF에 있던 텍스트를 검색하거나 복사하는 기능은 사라집니다. 텍스트를 그대로 살리고 싶다면 이미지 대신 Word로 변환하는 방법을 고려해보세요. 모든 처리는 브라우저 안에서만 이뤄지고 서버로 전송되지 않습니다.

자주 묻는 질문

여러 페이지를 한 번에 압축(ZIP)해서 받을 수 있나요?

아니요. 이 도구는 페이지별로 개별 다운로드 링크만 제공하며, 여러 페이지를 압축파일 하나로 묶어 한 번에 내려받는 기능은 없습니다. 페이지가 많다면 하나씩 다운로드해야 합니다.

어떤 이미지 형식으로 변환되나요?

PNG로 변환됩니다. JPG나 WebP 등 다른 형식을 선택하는 옵션은 없습니다.

몇 페이지까지, 얼마나 큰 파일까지 변환할 수 있나요?

최대 20MB, 최대 300페이지까지 지원합니다.

텍스트가 있는 PDF도 이미지로 바뀌면 글자를 검색할 수 없나요?

맞습니다. 변환된 PNG는 순수 이미지이므로 원본 PDF에 있던 텍스트를 검색하거나 마우스로 선택하는 기능이 사라집니다. 텍스트를 그대로 유지하려면 PDF를 이미지가 아니라 Word로 변환하는 것을 고려하세요.

PDF가 서버에 업로드되나요?

아니요. 변환은 브라우저 안에서만 이뤄지며, PDF 파일이 어떤 서버로도 전송되지 않습니다.

변환한 이미지 용량이 너무 크면 어떻게 줄이나요?

다운로드한 PNG를 이미지 압축 도구에 다시 넣어 품질을 조절하면 용량을 줄일 수 있습니다. PDF 자체의 용량을 줄이는 방법은 PDF 파일 용량 줄이는 법을 참고하세요.
