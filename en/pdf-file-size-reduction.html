How to Reduce PDF File Size (for Scanned and Photo PDFs)

A workaround that works well for scans, and a clear note on when not to use it.

← All guides

The honest premise: we don't compress PDFs directly

The PDF tools on this site convert PDF pages to images, combine images into a PDF, and handle a few conversions. They do not have a "compress this PDF" button. There is, however, a workaround that works well for one specific kind of file.

The workaround: extract, compress, rebuild

1) Convert the PDF pages to images with the PDF tools. 2) Compress those images in the image compressor, choosing a quality that suits you. 3) Combine the compressed images back into a PDF. Because the images account for almost all of a scanned PDF's size, shrinking them shrinks the whole file.

Limits to know about: the PDF tools process up to 50 pages per workflow, so longer documents should be split into batches, and the image compressor handles up to 10 images per batch (with a ZIP download).

It only helps some PDFs

This works for scans and photo-heavy PDFs, where images make up most of the file size.

It does not work for text-based PDFs. Text is already tiny, so there is almost nothing to squeeze, and turning pages into images costs you the ability to select and search the text. For those files, use the size-optimization option in a word processor or PDF editor instead.

Results also depend on image type. Color-rich scans often shrink by more than 90% as JPG or WebP, while documents with flat colors, stamps or handwriting can do worse as JPG. If that happens, switch the output format to WebP. Our format comparison has the measured numbers.

FAQ

Can I upload a PDF and compress it directly?

No. The workaround of extracting pages, compressing the images and rebuilding the PDF is the way to do it here.

Will it work on a long text report?

Not well. Text is already small, and converting to images removes text selection and search.

How much smaller will a scanned PDF get?

It depends on the scan and your quality setting. The benchmark page shows measured reductions at each quality level.

Is the rebuilt PDF always smaller?

Usually, but not always. Graphic-style scans can grow if compressed as JPG; try WebP in that case.

What if my PDF mixes photos and text?

Every page becomes an image, so the text stops being selectable. If you need to keep the text, use a PDF editor's optimization feature.

Is my PDF uploaded anywhere?

No. All processing happens locally in your browser.
